## 🧩 About

**Mafia The Old Country Overlay** is a curated list of Mafia The Old Country open-source tools:

- **Overlays** — on-screen helpers, layout notes, overlay viewer, menu overlay
- **Quality-of-Life Helpers** — config manager, overlay notes, HUD tweaks
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### 🎮 Game Helpers
- Overlay Menu — toggle on-screen helper panel
- overlay Notes — visualize nearby points of interest
- Config Presets — save and load overlay settings
- Hotkey Toggle — quick show/hide overlay

### 🎨 Interface & Cosmetics
- HUD Customization — adjust overlay transparency and position
- Custom Themes — organize overlay colors and styles
- Minimal Mode — compact overlay for focused play

### 🏋️ Research Layout
- Practice Mode Notes — segment study on any layout
- Input Remap Notes — document control schemes
- Performance Overlay — monitor FPS and system stats
